# Text

`$generator->ext(TextInterface::class)` - opt-in add-on, interface `Quidam\Definitions\Addon\TextInterface`, default implementation `Quidam\Addon\Text`

Realistic looking text generated by a **Markov chain** from a real book. Words follow each other like in the book, so the text has natural word frequency, word lengths, punctuation and names - in the language of the book.

It's an add-on, not an extension, because it's much heavier: the book is a 177 KB constant and the model built from it takes ~9 MB per index size. It's registered, but nothing is loaded until you ask for it:

```php
use Quidam\Definitions\Addon\TextInterface;

$text = $generator->ext(TextInterface::class);
```

For neutral placeholder text without that cost use [`Lorem`](../extensions/lorem.md).

## Methods

| Method | Returns |
|---|---|
| `realText(int $min = 50, int $max = 200, int $indexSize = 2)` | `string` - text of `$min` to `$max` characters |
| `withCorpus(string $corpus)` | new `Text` generating from given corpus - this one stays unchanged |
| `Text::clearCache()` | static - frees models of all corpora (rebuilt on next use) |

Constructor: `new Text(RandomizerInterface $randomizer, ?string $corpus = null)` - `null` uses the `CORPUS` constant.

## Examples

```php
$text = $generator->ext(TextInterface::class);

$text->realText();
// 'The two species that had stopped me on the lever, and I felt then. I took my eyes grew accustomed to the well,
//  and their numbers had rather diminished than kept stationary. That would account for it.'

$text->realText(50, 200, 3);
// 'The German scholars have improved Greek so much. “Then there is the future,” said the Very Young Man. Just think!'

$text->realText(50, 200, 1);
// 'Well, that night. And the hearthrug. On this proceeding, but the spoke like a low hillocks beyond. The circling stars.'

$post = [
    'title' => $text->realText(20, 60),
    'body' => $text->realText(500, 2000),
];
```

## How it works

1. The corpus (book) is split into words
2. For every sequence of `$indexSize` words the generator remembers which words followed it in the book (with repetitions - frequent continuations are picked more often)
3. Text starts at a sentence start of the book, then the next word is picked by the previous `$indexSize` words
4. When the text is long enough, it's cut at the last sentence end within `$max` - or, when there's no sentence end keeping at least `$min` characters, at the last word with a dot added
5. Brackets and quotes without a pair (text can start or end inside them) are removed - `()`, `[]`, `“”`, `"` and opening `‘` (`’` is also an apostrophe - `won’t`, `Weena’s` - so it's never removed)

The model is built on first use (~10 ms, ~9 MB for the default corpus and index size) and **shared by all `Text` instances in the process** - a test suite creating a new Quidam for every test builds it once, not per test. Models are keyed by a hash of the corpus text: every corpus (default, `PlText`, a file loaded at runtime) has its own model, the same text is never built twice. See [Model cache](#model-cache). Generation takes a fraction of a millisecond. With seed the text is repeatable.

## Index size

`$indexSize` (1-5) is the number of previous words deciding the next one:

| Index size | Result |
|---|---|
| 1 | most random, often nonsense - words fit their neighbours only |
| 2 (default) | readable, varied - good balance |
| 3 | more correct, still varied |
| 4-5 | close to the book - most texts are quoted from it |

Measured with the default corpus (300 texts of 50-200 characters):

| Index size | Copied verbatim from the book | Unique texts |
|---|---|---|
| 2 | 1% | 100% |
| 3 | 29% | 98% |
| 4 | 69% | 95% |

Bigger corpus allows higher index sizes without quoting.

## Default corpus

H. G. Wells, *The Time Machine* (1895) - public domain novel, ~32 700 words (177 KB), neutral narrative with little dialogue. Prepared from the Project Gutenberg text: license header, title, contents and chapter titles removed, dashes written as ` – `. Project Gutenberg license applies to their distribution, not to the public domain text itself.

## Own corpus - other language or style

Use a text you have the right to use, i.e. public domain books. Three ways:

**At runtime** - from a file, a database, a test fixture:

```php
use Quidam\Addon\Text;
use Quidam\Definitions\Addon\TextInterface;
use Quidam\Definitions\Randomizer\RandomizerInterface;

// one-off copy - the shared $generator->ext(TextInterface::class) stays English
$polish = $generator->ext(TextInterface::class)->withCorpus(file_get_contents(__DIR__ . '/pan-tadeusz.txt'));
$polish->realText();

// for the whole generator - factory parameters are resolved by type
$generator = $generator->withDefinition(TextInterface::class, fn (RandomizerInterface $randomizer) => new Text(
    $randomizer,
    file_get_contents(__DIR__ . '/pan-tadeusz.txt'),
));
$generator->ext(TextInterface::class)->realText();
```

**As a class** - for language packs, the text is part of your code (no file reading). Extend the class and override the `protected const string CORPUS`:

```php
use Quidam\Addon\Text;
use Quidam\Definitions\Addon\TextInterface;

class PlText extends Text
{
    /**
     * Adam Mickiewicz, "Pan Tadeusz" (1834) - public domain
     */
    protected const string CORPUS = <<<'TEXT'
        Litwo! Ojczyzno moja! ty jesteś jak zdrowie. Ile cię trzeba cenić, ten tylko się dowie, kto cię stracił. Dziś
        piękność twą w całej ozdobie widzę i opisuję, bo tęsknię po tobie. Panno Święta, co jasnej bronisz Częstochowy
        i w Ostrej świecisz Bramie! Ty, co gród zamkowy nowogródzki ochraniasz z jego wiernym ludem!
        TEXT;
}

$polish = $generator->withDefinition(TextInterface::class, PlText::class);
$polish->ext(TextInterface::class)->realText(30, 120, 1);
// or without registration
$generator->ext(PlText::class)->realText(30, 120, 1);
// 'Litwo! Ojczyzno moja! ty jesteś jak zdrowie. Ile cię stracił. Dziś piękność twą w Ostrej świecisz Bramie!'
```

Corpus tips:

* more text means more variety - a novel (tens of thousands of words) allows index size 3 without quoting
* line breaks and indentation don't matter (all whitespace is one space)
* sentences should start with an uppercase letter and end with `.`, `!` or `?` - generated text starts and ends at them
* remove what isn't prose - titles, chapter headings, contents, poems - otherwise they appear in generated text
* dialogue in `“ ”` (or `"`) quotes works best; straight single quotes `'` can't be told from apostrophes, so they may stay unpaired in generated text - convert them to `“ ”` in your corpus
* domain texts give domain style - i.e. product reviews corpus generates review-like text
* the corpus of a style can be used next to the default one - `ext(PlText::class)` and `ext(TextInterface::class)` are separate instances with separate models
* empty corpus throws `InvalidArgumentException`; a corpus without any sentence start throws when generating

## Model cache

| | |
|---|---|
| key | xxh128 hash of the corpus text - not the class name, so a corpus passed at runtime can't get another corpus' model |
| shared | by all `Text` instances (and subclasses) in the process, also across Quidam instances |
| built | once per corpus and index size, on first `realText()` with it |
| memory | ~9 MB per corpus and index size for the default book (less for smaller corpora), kept until the process ends |
| freeing | `Text::clearCache()` - i.e. in long running workers (queues, Swoole, RoadRunner) after a batch |

The model depends only on the corpus text, never on the randomizer - sharing it doesn't change seeded output, and `with*()` / `fork()` still start with a fresh random sequence. Template's `{{ text.realText }}` uses the same service.

## Own accessor

To get `text()` in your project, add it to a `Quidam` subclass (see [Own accessors](../quidam.md#own-accessors---extending-quidam)):

```php
use Quidam\Quidam;
use Quidam\Definitions\Addon\TextInterface;

readonly class AppGenerator extends Quidam
{
    public function text(): TextInterface
    {
        return $this->ext(TextInterface::class);
    }
}

AppGenerator::create()->text()->realText();
```

## Notes

* `$min` and `$max` are inclusive, `$max` at least 10, `$min` at least 1
* when the corpus can't produce text in given range (i.e. very long text from tiny corpus), `OverflowException` is thrown after 100 attempts
* short ranges (below ~60 characters) often end at a word instead of a sentence end - sentences are longer
* for neutral placeholder text use [`Lorem`](../extensions/lorem.md), for codes and masks [`Strings`](../extensions/strings.md)
